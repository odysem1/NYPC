NYPC 턴제 전략 게임 - 기초 전략 정리

목표
- 우선 성장형 AI 1개, 공격형 AI 1개를 각각 독립적으로 만든다.
- 처음부터 최적 전략을 만들기보다, 성격이 뚜렷한 baseline 전략을 만든다.
- 이후 둘을 대결시켜 보고, 맵에 따라 어느 쪽이 유리한지 판단하는 하이브리드 전략으로 발전시킨다.


============================================================
1. 성장형 AI: 가까운 거점 확보 + 경제 안정형
============================================================

핵심 목표
- 가까운 거점에 기지를 건설한다.
- 기지에 전사를 배치해서 노동 수입을 확보한다.
- 본부와 기지를 업그레이드한다.
- 병력을 꾸준히 생산한다.
- 후반에는 경제력과 병력 수로 상대를 압박한다.

기본 운영 흐름
1. 가까운 거점 확보
2. 기지 건설
3. 전사 배치로 수입 확보
4. 본부/기지 업그레이드
5. 훈련으로 병력 유지
6. 중앙 장악 또는 상대 방향으로 전진

초반 전사 배치 예시
- 1명: 가장 가까운 내 쪽 거점으로 이동
- 1명: 두 번째 가까운 거점 또는 중앙 방향으로 이동
- 1명: 본부에 남아서 노동/방어

매 턴 판단 순서
1. 내 전사가 있는 거점 중, 내 건물이 없고 적 전사가 없는 곳이 있으면 기지 건설
2. 이미 지은 기지나 본부에 전사가 충분히 있으면 업그레이드
3. 금화가 충분하면 훈련
4. 놀고 있는 전사는 가까운 미점령 거점으로 이동
5. 그래도 남는 전사는 중앙 또는 전방 기지로 이동

좋은 목표 거점 기준
- 내 본부에서 가깝다.
- 중앙에 너무 가깝지는 않아서 초반에 빼앗기기 어렵다.
- 상대 본부보다 내 본부에 더 가깝다.
- 가능하면 중앙 또는 상대 방향 길목에 있다.
- 기지를 지었을 때 수입원과 방어선 역할을 동시에 할 수 있다.

간단한 거점 점수
- 1차 버전에서는 score = dist(my_hq, stronghold)가 작은 거점 우선.
- 나중에는 중앙 접근성, 상대 경로 차단 정도, 인접 구역 수 등을 추가한다.

성장형의 장점
- 기지가 수입과 방어를 동시에 제공한다.
- 시간이 지날수록 병력과 경제가 안정된다.
- 장기전에서 본부 체력, 건물 수, 병력 수 우위를 만들기 쉽다.

성장형의 약점
- 첫 기지까지 거리가 멀면 초반이 약하다.
- 기지 건설에 돈과 전사를 쓰는 동안 병력이 부족해질 수 있다.
- 상대 공격형이 첫 거점이나 본부를 빠르게 압박하면 무너질 수 있다.

최소 방어 규칙
- 내 본부 근처에 적 전사가 보이면 훈련 우선.
- 내 본부에 전사가 1명도 없으면 하나는 본부로 복귀.
- 성장형이라도 초반 병력 생산을 너무 아끼지 않는다.

성장형 v1 목표
- 가장 가까운 거점 2개를 목표로 삼는다.
- 초기 전사 2명을 각각 보낸다.
- 도착하면 기지를 짓는다.
- 본부에서는 매 턴 가능한 만큼 훈련한다.
- 기지/본부에 전사가 있으면 돈 되는 대로 업그레이드한다.
- 남는 전사는 가장 가까운 내 건물로 보내 노동하게 한다.


============================================================
2. 공격형 AI: 초반 병력 압박형
============================================================

핵심 목표
- 초반부터 병력을 많이 생산한다.
- 중앙 또는 상대 첫 확장 거점으로 빠르게 이동한다.
- 상대 기지 건설을 방해한다.
- 상대 병력을 본부와 수비에 묶어 둔다.
- 병력 우위가 생기면 상대 본부를 압박한다.

중요한 관점
- 공격형의 1차 목표는 반드시 상대 본부 파괴가 아니다.
- 더 현실적인 목표는 상대의 첫 성장 타이밍을 방해하는 것이다.
- 상대가 기지를 짓기 전에 거점이나 길목에 병력을 보내면 상대 확장을 늦출 수 있다.

기본 운영 흐름
1. 초반 가능한 만큼 훈련
2. 초기 전사들을 중앙 또는 상대 쪽 주요 지점으로 이동
3. 새로 뽑은 전사도 계속 전방으로 이동
4. 상대 첫 기지 후보나 길목을 압박
5. 상대 수비가 약하면 본부 공격
6. 막히면 병력 집결 후 재압박

초반 운영 예시
- 1~3턴: 가능한 만큼 훈련
- 초기 3명: 중앙 또는 상대 쪽 주요 거점으로 이동
- 새로 뽑은 전사: 계속 전방 목표로 이동
- 기지 건설/업그레이드는 거의 하지 않음
- 단, 본부 방어를 위해 최소 1명 정도는 남기는 안정형 변형 가능

매 턴 판단 순서
1. 금화가 되면 가능한 만큼 훈련
2. 정지 상태인 전사는 전방 목표로 이동
3. 내 본부에 전사가 너무 적으면 1명은 방어
4. 업그레이드는 하지 않거나, 본부 수리만 예외적으로 수행
5. 전방 병력이 충분히 모이면 상대 본부로 압박

공격형의 목표 지점 후보
- 중앙 구역
- 상대 본부와 가까운 거점
- 상대가 첫 기지로 삼을 만한 거점
- 상대 본부로 가는 최단 경로의 중간 지점
- 내 본부에서 상대 본부로 가는 최단 경로의 2/3 지점

간단한 목표 지점 선정
- path = my_hq에서 opp_hq까지의 최단 경로
- target = path[길이 * 2 / 3]
- 처음에는 상대 본부 직행보다 이 지점으로 병력을 모은다.
- 전방에 병력이 충분히 모이면 그 다음 상대 본부를 목표로 한다.

공격형의 장점
- 상대가 기지를 짓기 전에 확장을 방해할 수 있다.
- 상대를 방어적으로 만들 수 있다.
- 상대가 성장형으로 욕심을 내면 초반에 크게 흔들 수 있다.

공격형의 약점
- 상대가 길목에 기지를 안정적으로 세우면 막히기 쉽다.
- 초반에 훈련과 이동에 금화를 많이 써서 경제 기반이 약하다.
- 한 번 막히면 보급비와 낮은 수입 때문에 시간이 갈수록 불리하다.
- 무작정 상대 본부로 돌격하면 포탑과 수비병에 병력이 녹을 수 있다.

공격형 v1 목표
- 본부에서 매 턴 가능한 만큼 훈련한다.
- 초기 전사와 새 전사를 모두 전방 목표로 보낸다.
- 전방 목표는 상대 본부 최단 경로의 2/3 지점으로 잡는다.
- 전방에 병력이 모이면 상대 본부로 보낸다.
- 업그레이드는 하지 않는다.

3. 구현 구조 제안
============================================================

샘플 코드에서는 decide()만 갈아끼우는 방식으로 시작한다.

예시 구조:

static Actions decide_growth(const GameState& S, const GameMap& M, const Paths& P, int turn) {
    Actions a;
    // 성장형 로직
    return a;
}

static Actions decide_aggressive(const GameState& S, const GameMap& M, const Paths& P, int turn) {
    Actions a;
    // 공격형 로직
    return a;
}

static Actions decide(const GameState& S, const GameMap& M, const Paths& P, int turn) {
    return decide_growth(S, M, P, turn);
    // return decide_aggressive(S, M, P, turn);
}

이렇게 해두면 한 줄만 바꿔서 성장형/공격형을 비교할 수 있다.


============================================================
4. 개발 순서
============================================================

추천 순서
1. 성장형 v1 구현
2. 공격형 v1 구현
3. 둘을 서로 붙여보기
4. 로그를 보고 약점 확인
5. 맵 평가로 둘 중 하나를 선택하는 하이브리드 전략 만들기

성장형을 먼저 추천하는 이유
- 거점 판단, 기지 건설, 업그레이드, 훈련, 전사 배치, 수입 유지 등 게임의 기본 구조를 많이 다루게 된다.
- 상태 관리 연습에 좋다.

공격형은 그 다음에 만들기
- 훈련, 전방 목표 선정, 정지 전사 이동이 핵심이라 코드 구조는 더 단순하다.
- 대신 좋은 목표 지점 선정이 중요하다.


============================================================
5. 최종 방향
============================================================

처음부터 순수 공격형/순수 성장형 중 하나만 고르지 않는다.

먼저 두 가지 baseline을 따로 만든다.
- 성장형: 안정적인 경제와 방어선 구축
- 공격형: 상대 첫 확장 방해와 초반 압박

그 다음 맵과 상대 움직임을 보고 전환하는 하이브리드 전략으로 발전시킨다.

최종 목표:
- 내 좋은 거점이 가깝다 → 성장형
- 상대 좋은 거점이 있고 내가 방해 가능하다 → 공격형
- 상대 러시 조짐이 있다 → 방어 성장형
- 양쪽 다 거점이 별로다 → 병력 중심 중앙 장악
