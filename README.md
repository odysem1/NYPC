# NYPC 2026 — 턴제 전략 게임 AI

2026년 NYPC에 참가해 생성형 AI를 활용하여 C++ 기반 턴제 전략 게임 에이전트를 개발했습니다.

## 1. 프로젝트 개요

주어진 맵에서 병력을 생산하고 거점을 확보하며, 자원을 관리해 상대 본진을 공격하는 턴제 전략 게임입니다.

단순히 병력을 많이 생산하는 것뿐 아니라 기지 건설과 업그레이드를 통한 경제력 확보, 병력 배치, 공격 시점 등을 함께 고려해야 했습니다.

개발 과정에서는 생성형 AI를 코드 작성과 수정에 활용했고, 전략 설계와 시뮬레이션 결과 분석을 중심으로 개선을 진행했습니다.

## 2. 전략 설계 및 변경

### 초기 전략: 공격형과 성장형

처음에는 두 가지 전략을 나누어 설계했습니다.

- **공격형:** 초반부터 병력을 생산해 상대의 거점 확장을 방해하고 본진을 압박
- **성장형:** 가까운 거점을 확보하고 기지 건설·업그레이드로 경제력을 늘려 후반의 병력 우위를 확보

초기에는 맵과 상대의 행동에 따라 두 전략을 선택하는 방식을 고려했습니다.

하지만 초반 공격만으로는 상대 본진을 함락하기 어려웠고, 공격에 실패했을 때 경제력 차이로 불리해지는 문제가 있었습니다.

이에 두 전략을 단순히 전환하는 대신, **초반 거점 확장 → 상대 견제 → 경제적 우위 확보 → 병력 집중 및 본진 공격**으로 이어지는 통합 전략으로 방향을 변경했습니다.

## 3. 시뮬레이션을 통한 전략 개선

가장 어려웠던 부분은 경제 운영에서 상대 본진 공격으로 전환하는 시점을 결정하는 것이었습니다.

공격 조건을 완화하면 충분한 병력을 확보하기 전에 공격해 손실이 발생했고, 반대로 조건을 강화하면 유리한 상황에서도 공격이 늦어져 무승부로 끝나는 문제가 있었습니다.

초기에는 시뮬레이션 결과를 확인하고 조건을 조금씩 변경하며 테스트했지만, 하나의 조건을 수정하면 다른 상황에서 예상치 못한 결과가 발생하기도 했습니다.

이후에는 로그를 통해 문제의 원인을 추정하고, 공격 전환 조건과 경제력 판단 기준을 변경했을 때 발생할 영향을 먼저 검토한 뒤 수정하는 방식으로 개선했습니다.

제출 기한 이후에도 전략 개선을 이어가며 샘플 AI를 상대로 테스트했습니다.

## 4. 생성형 AI 활용

생성형 AI를 전략의 코드 구현과 수정에 활용했습니다.

저는 전략의 목표와 우선순위를 정하고, 시뮬레이션 로그에서 문제가 되는 상황을 찾아 수정 방향을 검토하는 데 집중했습니다.

특히 개별 조건을 수정할 때 다른 판단 로직에 미칠 영향까지 검토하면서, AI가 제안한 변경 사항을 그대로 적용하기보다 예상되는 결과를 함께 고려하려고 했습니다.
